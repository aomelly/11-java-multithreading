# 11.1. Счастливые билеты

[Условие на uLearn](https://ulearn.me/course/java/Zadacha_11_1_22775cad-22e5-4034-83ba-8f9f9f2e3195)

В исходном примере три потока меняли общие переменные `x` и `count`. Операция `x++` состоит из чтения, сложения и записи, поэтому два потока могли получить один номер или пропустить его.

В `Lucky` каждый поток проверяет свой диапазон и записывает найденные билеты в свой список. Главный поток запускает все три потока и читает каждый список после `join()`, когда его заполнение завершилось. Результаты выводятся по порядку. Для номеров от 1 до 999999 итог равен `Total: 55251`.

Откройте `pom.xml` в IntelliJ IDEA и запустите `Lucky.main`. Для запуска теста выполните `mvn test`.
